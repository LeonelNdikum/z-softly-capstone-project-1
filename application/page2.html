KEY AWS SERVICES

The Technology Behind ZSoftly

The final cloud architecture combines AWS networking, container orchestration, security, DNS and monitoring services to provide a reliable and production-oriented deployment.

🌐

Amazon Route 53

Provides DNS management and routes users to the application through a friendly domain name instead of exposing the load balancer DNS directly.

⚖️

Application Load Balancer

Receives public HTTP/HTTPS traffic and distributes requests across healthy ECS Fargate tasks.

🚢

Amazon ECS Fargate

Runs the Dockerized web application using serverless container infrastructure without managing EC2 servers.

📦

Amazon ECR

Provides a secure private registry for storing and managing the Docker image used by ECS.

🔐

Amazon VPC

Provides an isolated network environment with public and private subnets distributed across multiple Availability Zones.

📊

Amazon CloudWatch

Provides monitoring, metrics and centralized application logs for the ECS environment.

🛡️

AWS IAM

Controls access to AWS resources using roles and least-privilege permissions for ECS workloads.

🔒

Security Groups

Controls network traffic between the public load balancer and private ECS containers.

DESIGN OBJECTIVES

Built for Resilience and Security

🚀 Scalability

ECS Fargate allows the application to run multiple container tasks and scale according to workload requirements.

🛡️ Security

Containers are designed to run in private subnets while the public Application Load Balancer controls external access.

🔄 Fault Tolerance

Multiple Fargate tasks distributed across Availability Zones allow the application to continue operating when an individual task fails.
