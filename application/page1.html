APPLICATION OVERVIEW

A Modern Cloud-Native Application

This application is running inside a Docker container and will eventually be deployed on AWS ECS Fargate. The architecture is designed to demonstrate containerization, scalability, resilience, security and highly available cloud infrastructure.

🐳

Docker

The application is packaged as a Docker container for consistent and portable deployment.

☁️

AWS Fargate

Serverless container infrastructure designed to run the application without managing servers.

⚖️

Load Balancer

Application traffic will be distributed across healthy container instances for resilience.

🛡️

Security

The infrastructure will follow AWS security best practices and least-privilege principles.

About This Capstone

The ZSoftly Cloud Capstone Project demonstrates how a containerized web application can be designed and deployed using AWS cloud services. The final solution will use Amazon ECR, ECS Fargate, Application Load Balancer, Route 53, VPC, IAM and CloudWatch to provide a secure, scalable and resilient environment.
